Build a settings page at /settings for a small reading-list app called Shelf, in Dylan's design system, dfdl (docs: https://dfdl-ui.fernandezdelaradylan.workers.dev, plain text for agents at https://dfdl-ui.fernandezdelaradylan.workers.dev/llms.txt).

The page has four sections:

1. Profile: the user's avatar (initials are fine), display name and email fields, and a Save button that confirms the save.
2. Notifications: three on/off settings: weekly digest, new followers, product updates.
3. Appearance: theme, one of light, dark or system. Make it actually switch the page's theme.
4. Danger zone: delete account, with a confirmation step before anything happens.

Install whatever you need. Make it work at phone width as well as desktop. When you are done, `npm run lint` and `npm run build` must pass. Do not ask questions; make reasonable choices and finish.
