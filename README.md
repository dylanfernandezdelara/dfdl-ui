# dfdl ui

Dylan Fernandez de Lara's design standard as an installable package: tokens, components, an agent skill, a lint policy, and a Figma library. Built so future projects start from the same taste without re-explaining it.

Status and phases: [`PLAN.md`](PLAN.md). Every approved value and why: [`decisions.md`](decisions.md). Research behind it: [`research/`](research/). Agent instructions: [`AGENTS.md`](AGENTS.md).

```bash
npm install
npm run dev      # http://localhost:3000, press g for the 8/24 grid
npm run check    # lint (incl. design-system policy) + typecheck
```
